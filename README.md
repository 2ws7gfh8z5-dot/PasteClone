# PasteClone 🚀

一个跨平台的剪贴板管理工具（macOS 原生版 + Windows 客户端），让复制粘贴变得简单丝滑。

![Swift 5.0+](https://img.shields.io/badge/Swift-5.0%2B-orange)
![License MIT](https://img.shields.io/badge/License-MIT-green)

> macOS（Apple Silicon + Intel）与 Windows 版本继续正常更新。

## ✨ 主要特性

- 📋 **剪贴板历史** - macOS 原生客户端保存文本、富文本、图片、文件和颜色；Windows 客户端当前保存纯文本
- 🔍 **模糊搜索** - 按顺序命中的字符即可匹配，`gth` 也能找到 `github`；文本与来源 App 名称同时参与排序
- ⌨️ **数字键速贴** - 面板中按 `1`–`9` 直接粘贴对应行，每行左侧有编号角标
- 🎯 **一键粘贴** - 点击历史项自动恢复来源应用并粘贴（需辅助功能权限）
- 📌 **智能组织** - 收藏夹、置顶、粘贴队列、按 App 排除
- 🎨 **暖色纸张质感 UI** - 奶油纸底、墨色文字与陶土橙强调色，深浅两套主题
- 🖥️ **真实来源图标** - 每行显示复制内容来自哪个 App
- 🔒 **隐私优先** - 密码管理器等敏感粘贴板类型自动跳过，可暂停记录或只忽略下一次
- 💾 **数据可携带** - 历史可导出为 JSON，也可导入合并
- 🧠 **本地画像分析** - 用系统 NaturalLanguage 框架在后台推断职业与偏好，纯本地运行，默认关闭
- 🔧 **系统集成** - 菜单栏驻留、开机启动、快捷指令（App Intents）自动化

## 🌓 外观模式

偏好设置支持三种外观：

- **跟随时间**：使用系统当前时区，07:00–18:59 为浅色，其余时间为深色；
- **始终浅色**；
- **始终深色**。

自动模式每分钟检查一次时间，不需要重启应用。

## 🖥️ 平台能力边界

### macOS 原生客户端（完整功能）

支持图片、RTF/RTFD、文件、颜色、菜单栏、开机启动、隐私排除、收藏夹、粘贴队列、自定义快捷键、模糊搜索、JSON 导入导出和自动/浅色/深色主题。提供 Apple Silicon + Intel Universal 安装包，最低 macOS 14。

### Windows 客户端

Rust + egui 客户端支持纯文本历史、持久化、搜索、置顶、删除、清理未置顶、`Ctrl+Shift+V` 全局热键、键盘导航和一键粘贴。暂不包含图片、富文本、文件、托盘、隐私排除、收藏夹、粘贴队列和设置页面。

### Linux（暂停更新）

1.8.0 起不再发布 Linux 版本，详见顶部公告。历史版本位于 Release 页面，不再提供支持。

## 🚀 快速开始

### 安装（macOS）

1. 打开 [最新 Release 页面](https://github.com/2ws7gfh8z5-dot/PasteClone/releases/latest)，在 Assets 里下载文件名以 `macos-universal.dmg` 结尾的安装包（同名的 `.zip` 是同一份应用的压缩版）
2. 打开 DMG，将 `Just Paste.app` 拖入 Applications 文件夹
3. 首次打开时如果提示"无法验证开发者"，在 Finder 中右键点应用 → 打开 → 再点"打开"
4. 按提示授予**辅助功能**权限（系统设置 → 隐私与安全性 → 辅助功能）

### 安装（Windows）

下载 `PasteClone-Windows-x86_64.zip`，解压后直接运行 `pasteclone-desktop.exe`。首次运行若被 SmartScreen 拦截，点"更多信息" → "仍要运行"。

### 首次使用

1. 启动后应用进入菜单栏，不占用 Dock
2. 按 `⇧⌘V` 打开剪贴板历史面板
3. 复制任意内容，自动记录
4. 按 `1`–`9` 直接粘贴对应行，或 `↑` `↓` 选中后回车

## 📚 功能详解

### 剪贴板历史
- 自动监控和保存所有复制内容
- 支持文本、RTF/RTFD、图片、文件、颜色
- 去重：文本按内容、图片/富文本/颜色按 SHA-256 识别重复
- 单条上限 2 MB（文本与富文本），图片最长边压到 2048 px，单次最多记录 50 个文件

### 搜索
- 子序列模糊匹配，不需要连续输入
- 同时匹配正文与来源 App 名称，连续命中和词首命中优先
- 搜索时固定条目始终排在最前

### 收藏夹与置顶
- 创建自定义收藏夹分类
- 置顶重要项目（不会被"清除历史"和自动清理移除）
- 收藏夹菜单可切换筛选、移除分组

### 快捷键系统
- 3 个预设快捷键随意切换
- 完全自定义任意按键组合
- 在偏好设置中实时编辑

### 粘贴队列
- 把多个条目排成队列
- 每次点"粘贴队列"弹出队首并粘贴，队列为空时自动创建

### 隐私
- 密码管理器等敏感粘贴板类型自动跳过
- 可按 App 排除
- 菜单栏可暂停记录或忽略下一次复制
- 全部数据保存在本机，不上传

## v1.4.0 发布说明（2026-08-28）

- **四平台发布**：提供 macOS Universal（Apple Silicon + Intel）、Windows 10/11 x86_64 和 Linux x86_64 安装包。
- **Windows/Linux 文本客户端**：支持文本历史、搜索、置顶、删除、清理、一键粘贴、键盘导航和 `Ctrl+Shift+V` 全局呼出。
- **原生平台验证**：Windows 与 Linux 安装包均由 GitHub Actions 对应系统 runner 测试和构建。
- **平台边界**：macOS 是完整客户端；Windows/Linux 当前为纯文本 MVP，暂不支持图片、富文本、文件、Collections、粘贴队列、隐私规则、托盘和完整设置页。
- **Linux 提示**：Wayland 下全局快捷键和输入注入受桌面环境及权限限制，X11 通常更稳定。

## v1.3.3 发布说明（2026-08-28）

- **交互更顺滑**：面板和列表滚动采用贝塞尔曲线；遵循 macOS“减少动态效果”。
- **输入不冲突**：搜索框聚焦后，`⌘C`、`⌘V`、`⌘F` 等交给系统文本编辑器处理。
- **跨平台推进**：新增可编译的 Windows/Linux 实验性 Rust 客户端，当前覆盖纯文本历史、搜索、固定、清除和一键粘贴。
- **平台边界**：macOS 仍是唯一完整正式客户端；Windows/Linux 尚未覆盖富文本、图片、文件、隐私规则、托盘和正式安装包。

## v1.3.2 发布说明（2026-08-28）
- 快捷键防误触：仅单独的 Command 组合会触发面板命令，带其他修饰键的组合不再误操作。
- 窄窗口布局：长文本与时间信息会安全截断，右侧一键粘贴和操作按钮不被挤压。
- 跨平台 CI：Windows runner 已配置 Swift 工具链并验证共享核心；Windows/Linux 完整桌面客户端仍在开发中。

## v1.3.1 发布说明（2026-08-28）
- 交互稳定性：历史行操作区始终预留宽度，悬停按钮出现时内容不再横向跳动。
- 操作反馈：固定、队列、删除按钮加入悬停与按压贝塞尔动效，并尊重 Reduce Motion。
- 防误触：移除列表行单击选择与双击粘贴的手势竞争；使用右侧常驻粘贴按钮可一键输入目标应用。
- macOS Universal：同一安装包支持 Apple Silicon 与 Intel，要求 macOS 14+。
- 跨平台基础：新增平台无关历史策略 Swift Package，并在 macOS、Windows、Linux CI runner 上验证共享规则。
- Windows/Linux：桌面客户端仍在开发，当前尚无可用安装包；请勿将 macOS 安装包用于其他系统。
- 安装包：GitHub Releases 提供 `.dmg` 与 `.zip`。
