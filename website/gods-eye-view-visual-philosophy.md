# Orbital Memory

视觉从一个深色、缓慢旋转的地球开始：它不是背景壁纸，而是一块持续运行的空间。地球的弧线、夜侧的光和细小的标记形成远景秩序；剪贴板面板以轻微偏转的纸张姿态压在其上，像把宏大的世界折叠成手边的记忆。

色彩保持克制，只让暖纸色、墨绿和橙色承担明确角色。橙色负责动作与回到光标的瞬间，绿色负责在线与可信的信号，纸张与暗地球之间保留足够的呼吸。材质要有触感，却不堆叠效果；每一条边界都经过耐心校准。

尺度采用由远及近的节奏：地球提供不可测量的广度，面板提供可触摸的细节，短标签像轨道上的坐标点。文字只承担锚定和署名，不解释画面已经表达的关系；留白是让运动被看见的结构，而不是空缺。

构图保持不对称但不失重心。地球向一侧偏移，面板以相反的微小旋转建立张力，前后层次通过边框、硬阴影和透明度完成。最终画面应像经过无数次微调的工作台：克制、清晰、细节经得起近看。

这套语言要求反复打磨而非增加装饰。每个像素都应体现深厚经验、精确间距和手工校准；作品必须像由顶尖设计师耗费大量时间亲自完成，安静却具有不可忽视的存在感。
